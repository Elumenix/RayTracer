This application uses YAML as input to the RayTracer. YAML input consists of a list of objects. Each object represents an element added to the scene or a reusable definition.

All members of a list are lines beginning at the same indentation level starting with a "- " (a dash and a space):

Every top-level entry begins with a hyphen (-).

Camera

Controls the viewpoint and generated image.

Property Required Description
add Yes Must be camera
width Yes Image width in pixels
height Yes Image height in pixels
field-of-view Yes Field of view in radians
reflection-depth No Maximum ray bounces
from No Camera position
to No Look-at position
up No Camera up vector 
- add: camera
  width: 512
  height: 512
  field-of-view: 1.0472
  from: [0, 0, -5]
  to: [0, 0, 0]
  up: [0, 1, 0]
Light

Adds a point light to the scene.

- add: light
  at: [0, 5, -5]
  intensity: [1, 1, 1]
  • add: Must be light.
  • at: Light position (Vec3).
  • intensity: RGB light color (Color).
Plane, Sphere, and Cube

All three objects use the same properties. 

- add: sphere
  material:
    color: [1, 0, 0]
  transform:
    - [translate, 0, 0, -3]
  • add: Object type.
  • material: Surface appearance.
  • transform: Position and orientation.

Materials determine how an object's surface interacts with light.

Property Default Description
color [1,1,1] Base RGB color
diffuse 0.9 Matte scattering
ambient 0.1 Background illumination
specular 0.9 Highlight brightness
shininess 200 Highlight sharpness
reflective 0 Reflectivity
transparency 0 Transparency
refractive-index 1 Light refraction
pattern None Surface pattern 
material:
  color: [1, 1, 1]
  diffuse: 0.1
  shininess: 300
  reflective: 0.9
  transparency: 0.9
  refractive-index: 1.5

RGB values must be between 0 and 1.

Patterns replace a material's solid color with a procedural surface design.

  • checkers - Checkerboard
  • stripes - Alternating stripes
  • gradient - Color gradient
  • ring - Concentric rings
  • radial - Radial pattern
  • blend - Blended colors/patterns
  • perturb - Randomized distortion
material:
  pattern:
    type: stripes
    colors:
      - [0, 0, 0]
      - [1, 1, 1]
Pattern Properties
  • type: Pattern type.
  • colors: Colors or child patterns.
  • seed: Random seed for perturb.
  • strength: Perturbation strength.
  • transform: Pattern positioning.
Standard patterns require exactly two colors. Perturb patterns require exactly one.

Transforms control the position, rotation, and scale of an object.

Operation Format
Translate [translate, x, y, z]
Scale [scale, x, y, z]
Rotate X [rotate-x, radians]
Rotate Y [rotate-y, radians]
Rotate Z [rotate-z, radians]
Shear [shear, xy, xz, yx, yz, zx, zy] 
transform:
  - [scale, 2, 2, 2]
  - [rotate-y, 0.7854]
  - [translate, 0, 1, -3]

Rotation values are specified in radians.

Define reusable materials, patterns, or transforms to avoid repeating configurations.

Define
- define: red-material
  value:
    color: [1, 0, 0]
    diffuse: 0.9
Use a definition
- add: sphere
  material: red-material
  transform:
    - [translate, 0, 0, -3]
Extend
- define: shiny-red
  extend: red-material
  value:
    specular: 1
    shininess: 300
  • define: New definition name.
  • extend: Existing definition to inherit from (optional).
  • value: Material, pattern, or transform configuration.
